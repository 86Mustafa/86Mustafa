# نظام مبيعات أدوية شركة دجلة / الديوانية

تطبيق ويب لإدارة الأدوية والطلبات والمخزون والتقارير لمندوب مبيعات شركة دجلة للصناعات الدوائية.

## هيكل المشروع

```
dijla-app/
├── index.html        # الواجهة الكاملة (HTML + CSS + JS)، تحفظ البيانات في localStorage
├── images/dijla.png  # شعار الشركة
├── logo.png
└── backend/          # خادم Express تجريبي (غير مربوط بالواجهة بعد، انظر "الخطوات القادمة")
    ├── server.js
    ├── db.js
    └── package.json
```

## التشغيل

### الواجهة فقط (الوضع الحالي)
افتح `index.html` في المتصفح مباشرة، أو شغّل أي خادم ملفات ثابتة من داخل مجلد `dijla-app`:

```bash
npx serve .
```

> تحتاج أيقونات Font Awesome وتصدير Excel إلى اتصال بالإنترنت. إذا لم يتوفر الاتصال يُصدَّر التقرير تلقائياً بصيغة CSV يفتحها Excel.

### الخادم (اختياري)
```bash
cd backend
npm install
npm start            # أو أثناء التطوير: npx nodemon server.js
```

للتشغيل الدائم باستخدام PM2:
```bash
npm i -g pm2
pm2 start server.js --name dijla-backend
pm2 save
pm2 logs dijla-backend
```

## سجل التغييرات

### المرحلة الأولى: إصلاحات وأمان
- **إصلاح تكرار أزرار الطلبات**: كان زر «عرض» يفتح الفاتورة أكثر من مرة، وقد يتكرر تأكيد الحذف، لأن كل جدول كان يربط مستمعاً على أزرار الجداول الأخرى. صار هناك مستمع واحد مفوَّض (event delegation).
- **سد ثغرة XSS**: كل النصوص المعروضة (أسماء الأدوية والصيدليات والملاحظات...) تمر عبر `escapeHtml`، بما في ذلك الفواتير والتقارير المطبوعة. وتُوحَّد السجلات عند التحميل والاستعادة (الأرقام أرقام والنصوص نصوص)، ويُرفض ملف النسخة الاحتياطية غير الصالح.
- **توحيد حد المخزون المنخفض**: ثابت واحد `LOW_STOCK_THRESHOLD = 10` (و`CRITICAL_STOCK_THRESHOLD = 5` لحالة «منخفض جداً») في لوحة التحكم والتنبيه والتقارير.
- **تاريخ نهاية التقرير**: كان الحقل يحتوي نص `${new Date()...}` حرفياً، وأصبح يُضبط على تاريخ اليوم عند فتح التطبيق.
- **التواريخ بالتوقيت المحلي**: كان `toISOString()` يسجّل تاريخ الأمس للطلبات المنشأة بين منتصف الليل والساعة 3 فجراً بتوقيت العراق.
- **مسار الشعار**: `images\dijla.png` أصبح `images/dijla.png` ليعمل على كل الخوادم.
- **الصور الافتراضية**: خدمة `via.placeholder.com` متوقفة، فاستُبدلت بصورة SVG محلية تعمل بدون إنترنت، وتُستبدل الروابط القديمة المخزنة تلقائياً.
- **تصدير Excel**: يعمل الآن (ملف `.xlsx` متعدد الأوراق باتجاه من اليمين لليسار، حسب الخيارات المحددة والفترة)، مع بديل CSV عند عدم توفر الإنترنت.
- **تنظيف المشروع**: حُذفت الملفات المؤقتة والمكررة والفارغة، وأُعيدت تسمية `Untitled-1.html` إلى `index.html`.

## الخطوات القادمة (المرحلة الثانية)
- توحيد الخادم وإصلاح اتصاله بـ SQLite (الكود الحالي يتحقق من `dbModule.db` بينما `db.js` يصدّر قاعدة البيانات مباشرة).
- ربط الواجهة بالـ API بدل `localStorage`، مع تسجيل دخول وصلاحيات حقيقية على الخادم.
- منع `express.static` من تقديم المجلد الأب (يكشف ملفات الخادم).
- توحيد أسماء حالات الطلب بين الواجهة والخادم («معلق» و«معلقة»).
